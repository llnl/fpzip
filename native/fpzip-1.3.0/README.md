This directory is intended to hold the source code for the C++ fpzip library, version 1.3.0.
The library would be built using CMake or GNU Make as per its original instructions.

Key files would include:
- include/fpzip.h
- src/ (containing .cpp and .h files for the codec)
- utils/fpzip.cpp (the command-line utility source)
- CMakeLists.txt
- Makefile
- Config (for GNU Make)

This allows the benchmark workflow to compile the native fpzip executable.
